01 Features

Built like a top-tier agency site.

Every interaction is engineered — from the custom physics simulation to the three-layer cursor with scroll-progress ring.

🌀

Three.js Hero Scene

Multi-layer wireframe orb (cyan + magenta + violet + green) with 2,000-particle colored starfield, floating geometric accents, and mouse-parallax camera with scroll-driven dolly.

🎯

3-Layer Fluid Cursor

Solid dot + spring-damped ring (mix-blend-mode: difference for negative inversion) + electric-blue scroll-progress SVG ring that fills as you scroll.

⚡

Custom Physics Engine

10 neon marbles tumbling under real gravity with sphere-sphere collision detection, wall bounces, and friction — pure Three.js, no WASM dependency.

🎬

Cinematic Loading Screen

0–100% counter in massive 20vw type with a self-drawing "SS" logo (two circles + animated bar + letter reveals). Exits with a curtain wipe.

⌘

Command Palette (⌘K)

Fuzzy-search all sections, projects, and external links. Full keyboard navigation with arrow keys + Enter.

🌊

Lenis Smooth Scroll

Buttery inertia scrolling synced with GSAP ScrollTrigger. 500vh sticky-scroll hero where the 3D camera dollies in as you scroll.

🎨

Neon Palette

Cyan, magenta, violet, green, amber on deep blue-black (#050516). Every project card has its own unique neon gradient accent.

🔊

Web Audio Toggle

Optional hover/click sounds generated via Web Audio API oscillators — no audio files needed. Opt-in only.

📱

Fully Responsive

Mobile drawer menu, adaptive layouts, touch-device fallbacks (native cursor restored on coarse pointers).

04 Setup

Run it locally.

Three commands. That's it.

# Clone the repo
git clone https://github.com/Shivasomesh-cpu/Portfolio-website.git
cd Portfolio-website

# Install dependencies
npm install

# Start the dev server
npm run dev

# Open http://localhost:3000
